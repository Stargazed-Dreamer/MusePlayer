# Skill 创建器 (skill-creator)

## 触发词
创建skill、新建skill、写个skill、优化skill

## 概述
为 MusePlayer 项目创建新的 Skill 文件，定义可执行的工作流指令。

## 前置条件
- 了解 `.agents/skills/` 目录结构和 `_index.md` 索引机制
- 明确新 Skill 要解决的具体问题

## 工作流

### 1. 意图捕获

明确以下信息：
- 核心意图：这个 Skill 解决什么问题？
- 触发场景：用户会说什么话来触发？
- 已有能力：`_index.md` 中现有 Skill 是否已覆盖？
- 输入输出：需要什么输入？产生什么输出？

### 2. 需求访谈

如果信息不完整，向用户提问（不超过 3 个问题）：
- 这个 Skill 的典型使用场景是什么？
- 有什么必须遵守的规则或限制？
- 预期的输入和输出是什么？

### 3. 编写 Skill 文件

按以下模板创建 `.agents/skills/{skill_id}.md`：

```markdown
---
name: {skill_id}
description: >
  {触发词和功能描述}
---

# {Skill 名称} ({skill_id})

## 触发词
{触发词1}、{触发词2}

## 概述
{一句话描述}

## 前置条件
- {需要什么依赖}

## 工作流
1. 步骤1：具体操作 + 对应的工具/API
2. 步骤2：...
3. 步骤3：...

## 关键规则
- 必须遵守的约束（用"必须""绝不"）
- 安全注意事项
- 异常处理策略

## 依赖
| 依赖 | 路径/接口 | 说明 |
|------|----------|------|

## 输入/输出
- 输入：{描述}
- 输出：{描述}
```

### 4. 同步与注册

- 在 `_index.md` 的 Skill 列表表格中添加新行
- 确认触发词不与现有 Skill 冲突

### 5. 测试验证

- 触发词匹配：说触发词能否正确匹配到新 Skill？
- 工作流可执行：按步骤走一遍是否可行？
- 依赖可用性：所有依赖是否就绪？

### 6. 迭代优化

根据测试结果补充细化。

## 关键规则

- **绝不写教程**：写指令，不写"你可以"；用"必须""绝不"，不用"建议""注意"
- **绝不模糊描述**：写"重试3次"，不写"适当处理"
- **绝不遗漏安全规则**：涉及文件操作、网络请求、数据修改时必须写明安全约束
- **绝不硬编码路径**：使用变量或配置，路径必须适配不同环境
- **绝不忘记更新索引**：创建 Skill 后必须更新 `_index.md`

## 依赖

| 依赖 | 路径/接口 | 说明 |
|------|----------|------|
| _index.md | `.agents/skills/_index.md` | Skill 索引注册 |

## 输入/输出
- 输入：用户的 Skill 需求描述
- 输出：新创建的 `.agents/skills/{skill_id}.md` 文件 + 更新后的 `_index.md`
